# Sudoku Solver

Windows için geliştirilmiş, çözüm tekniklerini görsel olarak incelemeye yardımcı olan masaüstü Sudoku uygulaması.

[En son sürümü indir](https://github.com/EmreArslan16384/SudokuSolver-Releases/releases/latest)

## Özellikler

- 81 karakterlik Sudoku metnini `0` veya `.` kullanarak içe aktarma
- Adayları otomatik yerleştirme ve gereksiz adayları temizleme
- Teknikleri adım adım arama ve bulunan hücreleri görsel olarak vurgulama
- Naked Single, Hidden Single, kilitli adaylar, kümeler ve çeşitli örüntü teknikleri
- Hücre koordinatları için farklı notasyon seçenekleri
- Kullanıcı girişlerini 81 karakterlik metin olarak dışa aktarma
- Klavye, fare ve dokunmatik yüzey desteği
- Yeni sürümler için GitHub Releases üzerinden otomatik güncelleme bildirimi

## Kurulum

1. [Son sürüm sayfasını](https://github.com/EmreArslan16384/SudokuSolver-Releases/releases/latest) açın.
2. **SudokuSolver-Setup.exe** dosyasını indirin.
3. Kurulum dosyasını çalıştırın ve ekrandaki adımları izleyin.
4. Kurulum tamamlandığında Sudoku Solver'ı Başlat menüsünden veya masaüstü kısayolundan açın.

> Windows, yayıncısı dijital olarak imzalanmamış uygulamalarda SmartScreen uyarısı gösterebilir. Dosyayı yalnızca bu resmi GitHub deposundan indirin.

## Güncellemeler

Uygulama açılırken GitHub Releases üzerinde daha yeni bir sürüm olup olmadığını denetler. Yeni sürüm bulunduğunda kullanıcıya bildirim gösterilir. İnternet bağlantısı olmaması uygulamanın normal kullanımını engellemez.

Her sürümün değişiklikleri ve SHA-256 dosya özeti ilgili [Releases](https://github.com/EmreArslan16384/SudokuSolver-Releases/releases) sayfasında yayımlanır.
